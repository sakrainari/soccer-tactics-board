# Soccer Tactics Board / 配信用サッカー戦術ボード

選手を動かしながら、サッカーの配置・戦術・交代を説明するブラウザ用ボードです。
操作画面と配信用画面を分けて、OBS のブラウザソースに表示できます。

## 機能

- 両チーム各11人とボールのドラッグ移動
- 選手名・背番号・ユニフォームカラー・主将マークの表示
- 4-3-3、4-2-3-1、4-4-2、3-5-2、3-4-3、5-4-1 の基本配置
- 移動矢印、パス矢印、ペン、半透明エリアの描画
- 前半／後半の左右切り替え
- 出場メンバーの文章から、先発・控え・監督を一括登録
- 選手名のダブルクリックによる交代、交代履歴の常時表示
- チームごとの得点変更とスコアボード
- 戻す／やり直す、配置ファイルの保存・読み込み、PNG 書き出し

## ダウンロード

GitHub のリポジトリ画面で **Code → Download ZIP** を選び、ZIP を展開します。
`index.html` と起動ファイルは、展開した同じフォルダーに置いて使ってください。

## まず試す

`index.html` をブラウザで開きます。インストール不要で、ボードの操作と保存を使えます。
普通の静的サーバーで開いた場合も、ブラウザ内に配置を保存します。

OBS とライブ連動する場合は、下記のローカルサーバーを使います。

## OBS とライブ連動

Python 3 が必要です。追加の Python パッケージは不要です。

Windows では、ダウンロードしたフォルダー内の `start-board.cmd` をダブルクリックします。
Python 3 または Codex の同梱 Python を検出して、ブラウザを開きます。
別のボードが起動中の場合は、8765〜8774 の空いているポートを使います。

ほかの環境では、フォルダー内で実行します。

```sh
python3 board-server.py
```

Windows の Python Launcher を使う場合：

```powershell
py -3 board-server.py
```

標準の URL：

- 操作画面：`http://127.0.0.1:8765/`
- 配信用画面：`http://127.0.0.1:8765/?display=1`

起動ファイルが別のポートを選んだ場合は、ブラウザに表示された URL を使ってください。
「配信用画面を開く」からも開けます。

OBS のブラウザソースに配信用 URL を指定します。履歴表示ありなら幅 **1600**・高さ **800**、
履歴を非表示にするなら幅 **1200**・高さ **800** がボードの比率です。
ローカルサーバーは、このパソコンからアクセスする `127.0.0.1` で動作します。

## メンバーを貼り付ける

「名簿を貼り付け・編集」から登録するチームを選び、次の形式を貼り付けます。

```text
[チーム名]
先発
GK 1 選手名
DF 4 選手名
...
控え
FW 18 選手名
...
監督
監督名
```

先発は11人、GKは1人で登録します。`(Cap)` は主将の印として読み取ります。
人数と背番号の重複を確認してから反映します。
名簿の順に現在の配置へ入るため、細かい戦術位置はドラッグで調整してください。

固定の入力例は [examples/japan-roster.txt](examples/japan-roster.txt) にあります。
これは作成時に提供された名簿の例で、最新メンバーを自動取得する機能ではありません。

## 保存

ローカルサーバー利用時は `board-state.json` に、単独利用時はブラウザ内に保存します。
`board-state.json` は Git の管理対象から除外しています。
大切な配置は「配置を保存」から別ファイルにも残してください。

詳しい操作は [USER_GUIDE.md](USER_GUIDE.md) を参照してください。
