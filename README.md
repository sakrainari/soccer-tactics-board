# Soccer Tactics Board / 配信用サッカー戦術ボード

選手を動かしながら、サッカーの配置・戦術・交代を説明するブラウザ用ボードです。
HTML を直接開いて使えます。「配信用表示」で操作パネルを隠し、OBS のウィンドウキャプチャ・画面キャプチャに表示できます。

## 機能

- 両チーム各11人とボールのドラッグ移動
- ボールを選手にくっつけて移動、引き離して解除
- 選手名・背番号・ユニフォームカラー・主将マークの表示
- 4-3-3、4-2-3-1、4-4-2、3-5-2、3-4-3、5-4-1 の基本配置
- 自分で作った配置に名前を付けて最大30件保存し、両チームの一覧から選択
- 移動矢印、パス矢印、曲線矢印、ペン、丸・四角のエリア描画、色・太さの選択
- Shift＋クリック・範囲選択で複数選手を選び、形を保ってまとめて移動
- チーム別の選択制限（重なった相手選手を通り抜けて操作）
- 控え一覧・ピッチ外の待機スペース・ドラッグによる交代候補の表示
- ピッチを固定し、右のメニューだけ独立してスクロール
- 重なった選手もポップアップなしで操作、名前の表示切替、100〜250%の拡大
- 表示構成「ピッチ優先／ピッチのみ／一覧を横並び」でピッチの大きさを選択
- 表示幅「標準／広く」、上部の配置リセットと線の一括消去
- レッドカードで退場選手をピッチ外へ表示
- 前半／後半の左右切り替え
- 出場メンバーの文章から、先発・控え・監督を一括登録
- 選手名のダブルクリックによる交代、交代履歴の常時表示
- チームごとの得点変更とスコアボード
- 配置を最大30コマ保存し、選手・ボールの動きを滑らかに再生（一時停止・速度変更・繰り返し）
- 戻す／やり直す、コマを含む配置ファイルの保存・読み込み、PNG 書き出し

## ダウンロード

GitHub のリポジトリ画面で **Code → Download ZIP** を選び、ZIP を展開します。
展開したフォルダー内の `index.html` を開くだけで使えます。

## まず試す

`index.html` をブラウザで開きます。インストール不要で、ボードの操作と保存を使えます。
普通の静的サーバーで開いた場合も、ブラウザ内に配置を保存します。

## 配信で使う

1. ZIP を展開し、`index.html` を Chrome・Edge などのブラウザで開きます。
2. OBS に **ウィンドウキャプチャ**（または画面キャプチャ）を追加し、このブラウザを指定します。
3. **配信用表示** を押すと操作パネルを隠せます。**H** キーで操作パネルに戻れます。
4. 必要に応じてブラウザを全画面表示にし、OBS 側でボードの部分を切り抜きます。

操作パネルを隠したまま選手とボールをドラッグできます。
起動用の cmd・PowerShell・Python は不要です。

## メンバーを貼り付ける

「名簿を貼り付け・編集」から登録するチームを選び、次の形式を貼り付けます。

```text
[チーム名]
先発
GK 1 選手名
DF 4 選手名
...
控え
FW 18 選手名
...
監督
監督名
```

先発は11人、GKは1人で登録します。`(Cap)` は主将の印として読み取ります。
人数と背番号の重複を確認してから反映します。
名簿の順に現在の配置へ入るため、細かい戦術位置はドラッグで調整してください。

固定の入力例は [examples/japan-roster.txt](examples/japan-roster.txt) にあります。
これは作成時に提供された名簿の例で、最新メンバーを自動取得する機能ではありません。

## ボールを選手に持たせる

ボールを選手の近くへドラッグして離すと、足元にくっつきます。
その選手を動かすとボールも一緒に動きます。ボールを選手から引き離すと解除し、
ほかの選手の近くへ置けば持ち手を変更できます。「ボールを離す」ボタンでも解除できます。
前半／後半の左右切り替えや配置の保存でも、ボールの持ち手を引き継ぎます。

## 自作フォーメーション

選手を自由に並べ、右の「ユニフォームと配置」で名前を入力し、「今の配置を自作として保存」を押します。
保存した形はフォーメーションの「自作フォーメーション」から選べます。両チームで共用でき、前半・後半とチームの向きに合わせて左右を反転します。

保存するのは11枠の位置です。呼び出すチームの選手名・背番号・色・交代履歴・退場状態を引き継ぎます。
「自作を上書き」で位置と名前を更新し、「自作を削除」で一覧から外せます。削除しても今の配置は残り、「戻す」で取り消せます。
自作はブラウザー内と配置ファイルに保存します。配置リセットは選択中のフォーメーションに戻します。

## ピッチを大きく表示する

上部の「表示構成」は「ピッチ優先」が初期設定です。控えと交代履歴を1列にまとめ、ピッチを大きく表示します。
「ピッチのみ」は控え・履歴パネルを隠し、ピッチに表示スペースを使います。名簿・交代履歴は保持します。
「一覧を横並び」は従来の表示で、控えと最新5件ずつの交代履歴を横に並べます。

ピッチ優先の履歴表示は各チーム最新2件です。履歴パネル、または「すべての交代履歴を見る」から全件を確認できます。
表示構成・表示幅はブラウザー内と配置ファイルに保存します。

## 曲線矢印と配置の再生

「曲線矢印」で始点から終点へドラッグし、曲がり具合を動かしてクリックで確定します。
実線の移動・点線のパスを選べます。Esc で確定前の曲線を取り消せます。

右の「配置の保存・再生」で現在の配置をコマに追加し、選手とボールを動かして次のコマを保存します。
2コマ以上で再生でき、Space キーで再生・一時停止、Esc または「停止」で再生前の配置に戻ります。
コマには選手・ボール・図・スコア・名簿・交代履歴を含み、配置ファイルにも保存します。

## 保存

配置は、開いているブラウザ内に自動保存します。
別のブラウザ・別のパソコンへ移すときは、配置ファイルを保存して読み込んでください。
大切な配置は「配置を保存」から別ファイルにも残してください。

詳しい操作は [USER_GUIDE.md](USER_GUIDE.md) を参照してください。
